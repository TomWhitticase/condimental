# Code of conduct

This project adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct, for everyone taking part in its issues, pull
requests, discussions and any other project space.

In short: be welcoming and considerate, critique work rather than people, and
do not harass anyone. Disagreement about the game's design is welcome and is
what the decision record ([docs/DECISIONS_LOG.md](docs/DECISIONS_LOG.md)) is
for; personal attacks are not.

## Reporting

Report unacceptable behaviour to the maintainer,
[@TomWhitticase](https://github.com/TomWhitticase), privately — or use
GitHub's "Report content" on the comment or issue concerned. Reports are
handled in confidence. The maintainer may remove, edit or reject comments,
commits, issues and other contributions that break this code, and may ban a
contributor temporarily or permanently, following the Covenant's enforcement
guidelines.
